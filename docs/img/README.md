# Screenshot folder

The iOS Shortcuts screenshots referenced by the READMEs are currently hosted
externally (image host) and embedded by URL, so no local PNGs are required.

If you'd rather vendor them into the repo, drop them here and switch the README
image links back to relative paths:

- `ios-app-opened.png` — Shortcuts → Personal Automation → "App … Is Opened" →
  Get Contents of URL action (POST app-event, action=open).
- `ios-app-closed.png` — same automation with action=close.

Suggested width ~600px so they render cleanly in the README.
